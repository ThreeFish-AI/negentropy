# lcc-tooling--panorama 图意简述（供统一渲染 archify 四件套）

- **主题**：Learn Claude Code「工具与执行」（s01–s04）全貌——一个主循环、一条裁决执行管线、一层生产保护。
- **三个容器（subgraph）与色彩语义**：
  - 循环本体（蓝 `#1f6feb`/`#79c0ff` 描边）：s01 的 while 循环骨架——用户输入 → UserPromptSubmit → 调用模型 → 判据。它是全图唯一不变的骨架，其余一切都挂在它上面。
  - 裁决与执行（绿=执行件 `#238636`，琥珀=闸门 `#9e6a03`）：s02 分发 + s03 三闸门 + s04 钩子共构的单次工具调用管线；「拒绝结果」与「执行结果」都汇入同一条 tool_result 配对回喂边，回指模型节点（闭环）。
  - 生产保护层（紫 `#8957e5`，虚线守护边）：CC 源码与官方文档提供的五个保护机制，各自虚线指向它守护/约束的骨架节点（needsFollowUp→判据、partition→执行、分类器→闸门 3、不变式→PreToolUse、stopHookActive→Stop）。
- **主链一条**：用户输入 → 模型 → 判据 → PreToolUse → 三闸门 → 查表执行 → PostToolUse → tool_result 配对 → 回到模型；两条旁路：判据否 → Stop 钩子（续跑/退出）；任一闸门拒 → 拒绝结果同样回喂。
- **深色模式**：全部节点采用深底亮字配色（GitHub dark 色系），描边用高亮度色保证暗背景对比度；渲染 light 主题时同组配色仍有足够区分度。
- **结论卡片建议（archify cards）**：①循环本体从 s01 到 s20 一行不改，能力全部外挂；②允许需要各方一致、拒绝只要一方摇头（hook 的 allow 压不过 deny/ask）；③教学 30 行与生产 1729 行共享同一骨架，差别全在保护层。
