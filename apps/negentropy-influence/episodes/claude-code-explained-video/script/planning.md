## 二、叙事策略

**主线问题（钩子→悬念→回答）**：让模型替你干活，为什么不是「模型变聪明了」？——悬念：
一间一百零二行的「诊室」怎么长到两百三十二行、而接诊循环那一页只换过一行字？——
回答：敢放权靠的不是更聪明的医生，是**不换的循环 + 长在循环外的三层外设**（一张表、
一道关、一圈节点）。

**母题实现方式（对齐 02 规格「视觉母题全片统摄 + 局部类比按难点准入」）**：本集的连续感由
**视觉母题**统摄——〔M-001 恒定视觉锚〕接诊循环装置（圆环 + 五步位 + 病历本槽位）锁死
描边色（core `#D97757`）与绝对线宽（5px）与刻度绝对值，全片每次出场**同形可缩放**（直径随镜
适配 280–340：定妆/特写/常规三档＋1-C 判停缩微环 183 拨杆局部视图——R12 补登，R10 对齐 as-built），只换周边标签；诊室制度名词
（病历本=上下文、开单=tool_use、贴回病历=tool_result、开单表=工具表、把关=权限、规程
节点=钩子）作为**贯穿名词系**保证指代稳定，**不塑造角色剧情、不建剧场**（对齐 02 的
「严禁升格世界观」纪律——诊室只借制度结构与名词，不借人物戏）；每个局部类比 1–3 句
点亮直觉即切回机制画面，零类比直讲合法。

**三条铁的叙事纪律**（来自源材料本身的递进结构）：
1. **行数进度尺**贯穿全片：P0 抛出 102 → P1 循环 102 → P2 加表 135 → P3 加关 180 → P4
   加节点 232 → P5 四格并排对账「循环只换过一行取值方式」。数字口径：站点徽章的教学
   叙事进度尺（【二】），source-notes 并记仓库实测 151/206/267/280（【一】）；口播明确
   说「教学版」体量，不与运行版混淆。
2. **破坏性实验用代码语言陈述**（cc_tools_lab 五实验=本仓【一】级）：实验效果一律说
   「虚拟文件系统里 4 个文件变成 0 个」「1 轮就停、0 个工具执行」——隐喻只借制度结构
   （开单/核对/签字/病历），**全片零伤亡映射、零医疗事故意象**。
3. **【三】级断言（课程作者对 CC 闭源源码的分析）口播前 3 句内必带归属句**（「有人把
   它的实现拆开看过，从那份拆解看……」）；【官】级带「官方文档」口径与日期敏感数字
   （如钩子事件 27→33）。

**记忆点节奏（约每 60–90 秒一个，全部回溯 source-notes）**：
- P0 「把话说完了，活，还得你自己干」（v1 词面「它在聊天框里说完了，活还得你来干」，R11 归锚 v2 定稿）／「医生只认这一本病历，每一轮都从头读」（原案「唯一的记忆」系禁词「记忆」同染——④ 必改 #8，2026-10-02 评审回写）

- P2 「新本事进表，不进循环」／「同一个未知名字，怎么取值，决定了是崩溃，还是改道」（实验 2；v1 词面「取值方式决定…」，R13 归锚 v2 定稿）

- P6 「医生开单，科室干活——放行的永远是关卡，不是医生」（R11 归锚：原「科室」系策划期旧词面，定稿 p3-26/p6-05＝「放行的，永远是关卡」）／「先找它的循环，再数它的挂件」

**理性收尾**：不贩卖焦虑；把「教学版是压缩件、真产品的规模远超于此」如实交代，悬念留在

  多 Agent、规划、记忆机制零预告（防串线）；BGM 留空轨。
