## 一、贴源叙事策略（v5：与源教学页章节一一咬合）

**全片六幕严格映射源页 s01 的章节结构，每幕讲透源页对应小节的全部要点**：

1. **P0 大模型的行动瓶颈 ↔ 源页 §问题**：大语言模型本质是无状态的文本预测器，输出命令后停在文本上；用户沦为「中间层」（源页原词）；定义替代人工搬运、驱动模型行动的外部程序外壳为 **Harness**；解法：一个自动循环，把执行结果喂回给模型，给它接上一双手。
2. **P1 一个循环就够了 ↔ 源页 §解决方案**：while True 一个循环、两个信号（有 tool_use 块 → 执行喂回继续；没有 → 退出）；三十多行代码亮相（源码 verbatim 上屏）；题眼 motto「一个工具 + 一个循环 = 一个 Agent」图形化。
3. **P2 五步工作原理 ↔ 源页 §工作原理**：五步因果闭环逐步行走查，每步「真实代码行 ↔ 消息列表 ↔ 环体站位」三联动（存入需求 → 调用 → 查内容块 → run_bash 执行 + tool_use_id 配对 → user 身份回塞回第二步）；组装成函数 = 最小可运行内核；分工公理（模型决策/程序执行）；后续章节叠机制而循环不变（匿名视觉层，不露章节名）。
4. **P3 试一下 ↔ 源页 §试一下**：仿真实终端跑源页原生 prompt（列 Python 文件 / git 分支），一轮调工具循环继续、一轮纯文本循环退出；点出源页「观察重点」；安全提示（临时测试目录）为视觉角标。
5. **P4 生产版源码对照 ↔ 源页 §深入 CC 源码附录**：30 vs 1729 基线标尺；判据之争（收尾字段流式迟到 → 误判丢调用【一】级消融结论一句】→ needsFollowUp 开关）；State 十字段；多条退出路径；全是保险丝。
6. **P5 收束与工具演进 ↔ 源页 §接下来 + 署源**：金句总结（规律 5）；回看单 Bash 工具的 cat/echo/find 三拼装（源页原词）；下期钩子（五个专业工具）；合规署源。

**v4→v5 退役清单**（贴源取舍，2026-11-15 用户批准）：购物清单加牛奶走查（gl-notes 自创非源页内容）退役，由源页 §试一下 prompts 取代；火警类比退役；完整消融分屏收编为 P4 一句实测佐证；「人肉搬运工」措辞贴源改「中间层」。

**声画咬合纪律**：
- P0：口播说「停住了」，终端窗口轻沉死寂；口播说「中间层」，双节点用户图标高速往返；口播说「给它接上一双手」，程序方块滑入接棒，陶土橙圆环闭合成环。
- P1：口播两个信号，环顶闸门两态实演（有块放行环转/空手侧门退出）；口播「三十多行」，源码面板铺开+行计数快滚。
- P2：口播五步，三联舞台「代码行→消息块→环体站位」三联动逐步发生；口播「以用户的身份」，角色色块对比闪。
- P3：口播两轮，终端真跑（命令执行、输出滚出、出口门开）。
- P4：打字机逐字到达+双指针时序错位+迟到徽章；判停章+调用坠落；needsFollowUp 致动连线；State 外圈与退出分支；保险丝层收束。
- P5：环体定格，金句卡浮现，灰色单手三串命令拼装断落，下期工具箱剪影，片尾署源卡。
