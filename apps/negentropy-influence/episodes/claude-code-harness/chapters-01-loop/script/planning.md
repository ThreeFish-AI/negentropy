## 一、公理化叙事策略

**全片如同搭建数学公理化体系，严格遵循因果闭环**：
1. **公理与原点（P0 大模型的行动瓶颈）**：大语言模型本质是无状态的文本预测器，输出命令后停在文本上；用户沦为手动搬运工；定义替代人工搬运、驱动模型行动的外部程序外壳为 **Harness**；提出核心解法：一个自动循环，把执行结果喂回给模型，给它接上一双手。
2. **核心机制与定理（P1 Agent Loop 核心机制）**：最小内核仅三十行代码，只认模型要不要调工具这一个信号；展开严密的五步因果闭环（存入需求 → 调模型 → 检查工具调用 → 执行工具 → 回喂结果）；明确分工公理：模型负责决策，程序负责执行。
3. **实例推导验证（P2 任务执行与回喂走查）**：带入具体任务（购物清单加牛奶并念出来），走查三次模型调用、两次程序执行的齿轮咬合过程，实证“每一步决策都踩在喂回的结果之上”。
4. **工程深潜与消融证伪（P3 流式工况与判据抉择）**：每圈转完凭什么判断？收尾字段 vs 内容块；引入生产环境必须面对的物理现实——流式传输（Streaming SSE）；剖析内容先到、字段后到的时序矛盾；消融实验证实：死等收尾字段导致多轮任务提前中断、工具调用静默丢弃；提炼工程铁律：面对流式工况，认内容事实，不认派生字段。
5. **工业生产映射（P4 Claude Code 源码对照）**：对照真实生产代码（Claude Code `src/query.ts` 1700 行）；证实内核与教学版完全同构（`needsFollowUp` 开关监听流式内容块）；解析多出的 1700 行是在外层应对不确定性的保险丝与安全气囊；提炼架构哲学：核心不用长大，长大的是保护外圈。
6. **收束与演进（P5 架构规律与工具演进）**：全片金句总结；首尾意象呼应（P0“接上一双手”与 P5“回看这双手”闭环）；揭示当前单 Bash 工具的笨拙与脆弱；引出下期钩子：给它换上真正的专业工具体系；合规署源。

**声画咬合纪律**：
- P0：口播说“停住了”，终端窗口轻沉死寂；口播说“手动搬运工”，双节点用户图标高速往返；口播说“给它接上一双手”，程序方块滑入接棒，陶土橙圆环闭合成环。
- P1：口播五步，环上五站牌位依次点火，侧边消息列表逐格长出；口播“用户身份塞回”，两角色标签条特写并列闪烁。
- P2：清单走查三轮，牛奶字符高亮长出，环体同步转动三圈，出口门变绿开启。
- P3：双指针时间轴展示流式到达时序，锁链图标具象化延迟；消融分屏左红坠落丢失、右绿十轮全通。
