## P1 一个循环就够了

> 画面：全景展现宏大 Harness 环形母体——它不是模型和终端之间的小圈，而是将左侧「LLM 认知芯片」与右侧「终端执行沙箱」彻底包裹在体内的高能闭环大圈！大圈外缘蚀刻 [HARNESS : AGENT LOOP]，统一的 Context 等离子数据流在模型与终端之间高能巡游；环顶矗立重型高压关卡闸门——tool_use 触发时电弧喷涌、放行加速；无调用时钛合金防爆门重压闭锁；随后三十行真码如瀑布垂下，动态等式 bash + LoopRing = Agent 迸发金色光晕

- [p1-01] 破局的解法，是一个包容一切的 Harness 宏观大圈。
- [p1-02] 模型在左，终端在右，全被圈在体内，由上下文贯穿两极。
- [p1-03] 圈内只要检测到工具调用，循环继续运转；没有调用，立刻凯旋退出！

- [p1-04] 把这套底座翻成 Python，核心循环居然只有三十多<行|HANG2>。
- [p1-05] 记住极简等式：外层 Harness 包裹大脑与终端，就是 Agent。

> 角标：while True · tool_use

## P2 五步工作原理

> 画面：高科技三联画舞台＝左侧真码逐步激光高亮 / 中央微缩全息大圈展现 5 个主语节点（User -> Harness -> LLM -> Tool -> Context）/ 右侧消息列层层堆叠；青碧色上下文数据流沿大圈贯穿闭环，2-G 打出五大主语分工铭牌

- [p2-01] 拆解统御全局的 Harness 闭环，五个节点主语清晰。
- [p2-02] 第一步主语是 User：用户输入需求，注入最初的目标种子。

- [p2-03] 第二步主语是 Harness：底座打包上下文与工具，驱动模型。

- [p2-04] 第三步主语是 LLM：模型认知决策，裁决回答还是调工具。
- [p2-05] 若裁决无需工具，出口闸门开启，整台 Harness 优雅退出。

- [p2-06] 第四步主语是 Tool：工具在终端执行，产生物理副作用。
- [p2-07] 每一份工具输出打上编号，铸造成标准的结果契约。

> 画面：消息角色标签特写——assistant「我要调工具」之后紧跟一条 user「这是你要的结果」，角色色块对比闪两下；编号配对签 #01 全程可追

- [p2-08] 第五步主语是 Context：上下文吸收结果，原子回填闭环！
- [p2-09] 记住铁律：凡不是模型自己思考的，全由上下文总线承载。

- [p2-10] 五大主语环环相扣，构成了最纯粹的 Harness 动力源。
- [p2-11] 用户给目标，底座管调度，模型做决策，工具搞执行，上下文做闭环！
- [p2-12] 无论往上叠多少机制，这个统御全局的五步心跳，恒定不变。


> 画面：拉回全函数——五枚括号锚全亮＝三十行内核；分工铭牌；后续章节以匿名小方块叠上环体外缘而环体本身一格不动

> 角标：messages · run_bash · tool_result · tool_use_id
