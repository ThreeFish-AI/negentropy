## P1 Agent Loop 核心机制（组件 P1FiveSteps）

> Morph Continuity（0-C→1-A）：同一主体=陶土橙环体。起止态：0-C 末帧小比例闭环 → 1-A 首帧主体级大环（五步站牌位随环展开）。中间态：推近过程描边色、线宽、圆度逐帧不变，仅尺度与伴随元素变化。身份线索：陶土橙描边+圆轮廓（保两项）。何时不该 morph：推近出现跳帧或环体重绘抖动，回退硬切+淡入。
