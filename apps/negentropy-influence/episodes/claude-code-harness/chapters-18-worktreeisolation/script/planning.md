## 二、叙事策略

**主线是一问一答的闭环**：开场抛问题「都改同一个文件，在哪干」→ P1 用「一账本多房各挂线 + 任务级绑定」回答「并行各改各的」→ P2 双房走查证明「真的踩不着、账还清楚」→ P3 反问「活干完了房怎么收」——清点守卫 + 三出口 + 消融实测回答「没有那道默认拒绝，一句口令就无声抹掉」→ P4 对照生产版「两个入口 + 一条边界（不是沙箱）」→ P5 收束「靠设施不靠自觉：房号入文件、收尾有守门」+ 下期钩子（外面现成的工具怎么接）。
