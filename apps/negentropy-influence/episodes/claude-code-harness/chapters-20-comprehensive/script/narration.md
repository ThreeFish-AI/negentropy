## P2 岔口与关卡

> 画面：全走廊唯一的岔口特写——响应包展开：内有工具调用块，箭头直行进执行段（确认绿）；没有，箭头靠边进收尾轨（恒定蓝）；失配边界字幕条随行

- [p2-01] 模型一开口，就到全走廊唯一的岔口。
- [p2-02] 判据只有一条：响应里有没有工具调用块。
- [p2-03] 有，接着走执行；没有，本轮就地收尾。
- [p2-04] 别误会：这条走廊没人推着谁走，岔口也只此一个。

> 画面：执行段三车道——危险卡被权限闸弹开（警示红）；常规件直行执行（确认绿）；慢活滑入旁侧后台轨、先发一张占位卡回执；干完之后事后钩检查输出体量

- [p2-05] 要动手了，先过权限闸。
- [p2-06] 一条删掉整个项目的命令、一个越界路径，一律拦下问过。
- [p2-07] 慢活滑进后台先回占位卡；干完还有事后钩看一眼，输出太大提个醒。

> 画面：镜头拉远——整条环形走廊全貌：外圈厚厚一圈设施格全亮（合流紫），环体本身仍是细线四拍节奏；字幕卡「周围变厚」

- [p2-08] 没有工具调用的一轮，收尾钩做统计，就地收官。
- [p2-09] 一圈走完，每一站都是往循环周围加东西——周围变厚，循环没变。
- [p2-10] 这份挂点表教的就是位置感，每件东西，挂在哪个位置。

> 角标：tool_use block · PreToolUse · permission · background task · PostToolUse · Stop hooks · while True

## P3 一句真输入
