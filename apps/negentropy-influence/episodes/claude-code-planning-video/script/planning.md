## 2. 叙事策略

**剧场（单一世界观，全片唯一）**：通宵不打烊的工坊——模型是手很快但从不记事的师傅，harness 是工坊本身。本集五角色严格沿 170 §2 台账单射：**台面**＝上下文窗口（本集主舞台）／**工序卡**＝待办清单／**副台**＝子 agent（只带回一张回执）／**抽屉标签与抽屉里的手册**＝技能目录与正文／**垫纸**＝system prompt；M5「补救梯」为 172 章自设比喻（传送带旁三级梯子，每级自带一道闸），与台账既有角色零撞义。「传送带」「门禁」为已建角色复用（P0 复述半句即出场，不涉任何顺序词）；三条防撞规则原文有效（台账第一条的通名禁用词全程回避、四个帮手不混用、三类卡片不同名）；类比每处 1–3 句即止、只承担结构同构不承担性能等同。

**主线问题（钩子→悬念→回答）**：
- 钩子（P0）：「它每一轮看到的东西，是谁决定的？」——师傅手快不记事，每轮开工把台面从头读一遍；看见什么不由师傅决定，由台面上摆了什么决定。台面以四种方式坑聪明的师傅：规矩被摊薄／过程长住台面／知识全额付费／一次事故整轮白干（第五件不安排台面、保住台面）。
- 悬念（P1–P5）：五件东西各管一环——工序卡把「还剩什么」钉回可见面（救注意力不救能力）；副台隔走过程只放结论上台（但隔离的是台面不是门禁）；抽屉把「知道有什么」与「读到内容」拆成两笔账（标签与手册寿命不同）；垫纸每轮按真实状态重铺（事实不是文本）；补救梯三级三闸（先判断后落笔）。另有一条副悬念线贯穿：**三连口径反转**（P1 任务工具默认态 →P2 派生递归默认 →P5 过载切模型）——「拆源码时的结论」与「官方现行口径」三度相撞，每幕一撞，构成「教学叙事 vs 产品现状」的节奏骨架。
- 回答（P6）：看见什么，从来不是它自己说了算——想什么是师傅的本事，看见什么是工坊的安排（本集遗产句）。

**记忆点节奏（约 60–90 秒一个，全片 14 个，全部可溯源 notes／brief §6 锚句白名单）**：锚句白名单——「它不增加动手的本事，只增加记得住的本事」／「它救的是注意力，不是能力」／「一次失败的更新，不会留下半张卡」／「副台只带回一张回执——回执上不写它有没有干完」／「隔离的是台面，不是门禁」／「干净上下文不等于空上下文」／「按名字取手册，所以没有路径可以骗它」／「手册会被收掉，标签不会」／「垫纸每轮重铺，看的是真实状态，不是你这句话」／「装配的依据是事实，不是文本」／「判断必须抢在落笔之前」／「顺序本身就是正确性」／「错误不是终点，是重试的起点——但每条退路都自带一道闸」／「看见什么，从来不是它自己说了算」。

**理性收尾原则**：不贩卖焦虑（错误叙事只讲机制与止损哲学，不渲染失控想象）；不裁决「规划外置 vs 内化」路线分歧（D1/C3——脚手架该随模型进步拆除还是本该永久存在，官方自己两头留后手）；「待办清单减少跑偏」一律以**设计主张**口径讲（负向清单：无对照实验、无漂移指标、无成功率数字），不伪装成测量结论。
