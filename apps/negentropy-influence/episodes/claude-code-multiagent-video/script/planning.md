**Logline**：一个 Agent 干不完的大活，直觉答案是「多开几个」，而真正要补的是一块任务板、一排收件箱、一套带编号的握手和几把锁——七件朴素设施，全部挂回同一个循环（gl-notes 一句话定位 + §1）。
