## 2. 叙事策略

**剧场（单一世界观，全片唯一）**：通宵不打烊的工坊——模型是手很快但从不记事的师傅，harness 是工坊本身。本集**零新增角色**：排工板（任务图）、收件格（邮箱）、派工单（协议）、班次（自治队友）、隔间（worktree）、标准插口（MCP）全部沿用 170 §2 台账单射；三条防撞规则原文有效（「桌子」禁用、四个帮手不混用、三类卡片不同名）；类比每处 1–3 句即止、只承担结构同构不承担性能等同。

**主线问题（钩子→悬念→回答）**：
- 钩子（P0）：「一个人干不完怎么办？」——台面摆不下整间工坊（上下文覆盖不了）、一双手串行、待办断电即失；答案不是更聪明的师傅，是一班组人共用的**五件朴素物件**。
- 悬念（P1–P5）：五件物件逐件登场——排工板（活放哪）→收件格＋派工单（怎么传话、怎么拍板）→班次（谁派活：没人派，自己看板）→隔间（在哪干）→插口（外接怎么进）；每件讲完都留一眼传送带，攒「机制很多、循环没动」的证据链。
- 回答（P6）：机制很多，循环一个；**多 Agent 机制只以两种身份入场：一条注入的消息，或工具架上的一个工具**（费曼遗产句，P6 落卡）；系列终章回响——五区全亮、「装置尽管加，循环不乱动」家规赠送。
