## 2. 叙事策略

- **视觉母题全片统摄**：一张「目录索引卡」（两行：name + description）作恒定视觉锚〔M-001〕——它是三级披露常驻层的具象化身：翻面=正文整载、侧栏抽卡=资源按需调阅；锁死描边色与线宽，跨幕同形出场只换周边标签。210 为去类比剧场的标准技术文档语体，**零贯穿剧场**；局部点亮只允许 1–3 句即切回机制画面。
- **开篇钩子**：按 RSI-039 出 4 个候选交人拍板（见下方矩阵）；p0-01 执行「这是 XXX……」句式，且与主干（三级渐进披露/生态极简）强关联。
- **主线问题**：教 AI 干活的知识，为什么不能在开工时全塞给它？→ 因为注意力是稀缺资源 → Agent Skills 用「目录常驻、正文按需」的三级账本，把固定成本改成使用成本 → 而这个极小标准的胜利与代价（路由靠一句话、安全靠自觉）。
- **记忆点节奏**（每 60–90 秒一个，全部取自事实源）：
  1. 20 技能 × 3000 token ≈ 6 万——开场白先被挤爆（§1，**示意算式口径**，画面带「示意估算」角标，gl-notes §10 对账行约束）；
  2. 39,222 vs 2,321 = **16.9×**——全量装载与目录常驻的账（§4/§10，lab2 复算【一】级）；
  3. OpenAI 的 2% 预算门——跨厂商在同一件事上达成共识（§4）；
  4. 「一根字符串决定路由」+ near-miss 负例（§5）；
  5. X2：严格校验砍掉 1/3 的跨端技能（§6，lab2 实测 33.3%）；
  6. X4：描述字段的缩进伪字段能把工具授权注入进来（§7）；
  7. 五条规律收敛：**核心资产是被解释的文本，不是被执行的代码**（§9）。
- **理性收尾**：不贩卖焦虑；悬念留在开放问题（§9 争议三：信任真空由谁补位——「很可能要等一次重大安全事件，才倒逼出标准层的防线」），尾幕给 §12 五条「材料没有证明的事」边界护栏卡。
