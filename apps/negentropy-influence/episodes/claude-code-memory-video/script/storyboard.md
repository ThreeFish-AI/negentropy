# 分镜：《AI 的记忆：会丢的和不能丢的》

> 逐字稿 SSOT：[narration.md](./narration.md)；视觉契约见 [planning.md](./planning.md) §三。
> 一镜 = 2–8 句连续句子共享同一主画面；句区间必须覆盖本幕每一句（`check_script.py` 强制）。
> 色名：`core` 陶土橙（系列锚）· `keep` 苔绿（本集己色：不丢层）· `mech` 石青（收拾机制）·
> `deny` 警示红。★丢失不用颜色画——被压内容向 `dim`/`panel` **褪色**，褪色即遗忘。
> **镜号必须与 `scenes/*.tsx` 的 `<Sequence name>` 逐字一致**。
