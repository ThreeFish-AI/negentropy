## 2. 叙事策略

**剧场（单一世界观，全片唯一）**：通宵不打烊的工坊——模型是手很快但从不记事的师傅，harness 是工坊本身。本集新增物件：**台面**（上下文窗口，只增不减）与**登记簿**（`.memory/`，台面之外的持久册子）。角色严格沿 170 §2 台账单射（收台四步／记录员／大件搬仓库／取货条／掐中段与工序卡回单配对／登记簿／扉页目录／目录员／夜班整理工）；main 演进四条类比归位（analogy-plan §二：刚出炉的大件直接进仓库／腾到够放就停手／条子地址须是本坊门牌／掐口不二刀）只进 P6 彩蛋段；三条防撞规则原文有效（「桌子」禁用、四个帮手不混用、三类卡片不同名）；类比每处 1–3 句即止、只承担结构同构不承担性能等同。

**主线问题（钩子→悬念→回答）**：
- 钩子（P0）：「一场对话结束之后，它还记得什么？」——师傅从不记事（记不住），台面还会先满（装不下）；一句话：记不住，还装不下。
- 悬念（P1–P5）：两本账分开记——会丢的（收台四步：用有损换无限，但丢得有章法：配对不拆／指针换空间／便宜的先跑）与不能丢的（登记簿：跨压缩跨会话，但写权不在师傅手里：目录员挑选／撂活抽取／夜班整理）。每本账各埋一处反直觉：会丢的那边，磁盘上还在的东西台面上找不到路；不能丢的那边，师傅自己一个字都写不进去。
- 回答（P6）：记忆不是一个功能，是两套咬合的机制——一套承认会丢，一套保证不丢；咬合在两端（写侧取压缩前快照／读侧压后重注入·官方）；彩蛋收尾：这个开源项目后来自己修了那条找不到的路（不宣称因果）。

**记忆点节奏（约 60–90 秒一个，全部取自 memory-brief §6 白名单与 source-notes 叙事素材，共 15 个）**：逐幕落位见分幕表；锚句白名单——「上下文总会满，要有办法腾地方」／「便宜的先跑，贵的后跑」／「编号是讲课的顺序，干活是另一套顺序」／「裁剪可以丢内容，不能丢结构」／「先抄地址，再扔东西——旧条子上只写了需要就重跑一遍」／「磁盘上的原文还在，台面上却没有路」／「摘要留得住目标，留不住口味」／「存档与记忆，是两回事」／「模型没有持久状态」／「压缩会丢细节，要有一层永不参与压缩的存储」／「扉页不是手写的，每次写完从头重排」／「用模型选，不用相似度」（【三】归属句）／「师傅不能自己往登记簿上写字，执笔的另有其人」／「跨会话的记忆管一辈子，会话记忆管这一场」／「记忆不是一个功能，是两套咬合的机制」。

**理性收尾原则**：不贩卖焦虑（遗忘叙事只讲机制代价，不渲染「AI 失忆失控」）；不裁决争议（模型自选 vs 向量检索：成本可测、召回零度量、官方不表态，悬念留开放判断）；教学版瑕疵如实讲但限定不外推（轨混禁令：不拿教学版瑕疵批评产品、不拿产品能力夸教学版）。

## 6. 边界与不做的事

- **BGM 留空轨**；本片 zh 单语（英文版触发条件＝用户明确要求）。
- **双轨口径纪律（本集最高优先）**：口播机制断言一律钉站点轨教学版——占位符为「重跑提示」型、不携磁盘指针；「先落盘再占位」的顺序不变式；扉页派生重建；两层加载讲做一致（站点轨两个注入点都在，**勿沿用旧精读「两层加载只讲没做」的 main 轨判定**，分歧 B1/简报 §1-M4）；main 演进（0dcafa2）只在 P6 彩蛋一段出现且限定「这个开源项目后来又改了一版」，照单记录收敛、不宣称因果；官方对照走「教学版教 X；官方文档说 Y」双句式。
- **去站点化（规则 7）**：口播／分镜／场景组件禁 learn.shareAI／Learn Claude Code／shareAI／「课程」／「站点」／章号 s01–s20——「这门课」同样在禁用面，指称信源一律「这个开源项目」；【三】断言归属句模板：「这个开源项目的作者拆过真实实现后说……」；【官】断言表述为「官方文档说……／明写……／确认……」。
- **活数据不进口播**：教学常量（触发条数／头尾保留／窗口／长度门／字符上限）定性表述；可引数字白名单＝单条输出可达 500KB（定性为「读一个大文件」）、预览 2000 字符、保尾 5 条、最多 5 条记忆、三十天清理（官 19）；绝对行数／工具数不引。
- **英文标识符只进画面角标**（messages／tool_result／prompt_too_long／compact／MEMORY.md／pre_compress／session memory 等，口播用中文机制名）；可进口播的英文词仅 Claude Code 与 Harness（术语规范）；Memory／session memory 口播降级为「跨会话记忆／会话记忆」＋角标补名。
- **反串线（规则 1）**：口播不出现他集标题／集数序号／「上一集／下一集／本系列」类顺序词；「下期」仅下期卡与收尾语一次；「工坊地图还有两个区没开灯」属机制陈述可用，不作集数指涉。
- **类比纪律**：角色单射沿 170 §2 台账＋制作期类比计划归位（新增四条仅 P6 彩蛋段）；三条防撞规则有效；类比 1–3 句即止，不承担性能等同。
- **画面纪律**：画面文字只放关键词／数字／标签（≤6 字），禁整句复述口播（双字幕教训）；storyboard 全文禁「archify full/inset」字面串（覆盖门全文计数）；全屏独占期间常驻装置让位。
