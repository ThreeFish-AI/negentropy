## 2. 叙事策略

**主线问题（双问，全片闭环）**：一次 AI 编码对话凭什么能跑一整天不崩？更奇怪的是，第二天它居然还记得你是谁？——P0 **两句连发抛完整双问**（后半问只抛不答）→ 钩子（草稿纸每次全量重发、写满即拒收 §1）→ 第一层答案：会话内省着花（§3）→ P3 转折**正式激活第二问**（新会话连摘要都没有 §1/§4 开篇）→ 第二层答案：跨会话挑着记（§4）→ P6 五规律卡同帧**显式回收双问**（「不崩，靠便宜的先跑；记得你，靠目录常驻、正文按需」）→ 开放问题收尾（长上下文会终结压缩工程吗 §8.2，不裁决）。

**视觉母题统摄 + 一物一喻继承**（对齐 gl-notes 附录 A）：
- 全片连续感由**双母题对置**统摄：**草稿纸**（会话内层：纸张+行线+逐轮增行的恒定几何，灰白冷色）与**卡片册**（跨会话层：卡片+索引页的恒定几何，苔绿）。两母题全片同形复现、只换内容标签〔M-001 恒定视觉锚〕；系列 3D 装置（HarnessStack/HarnessBadge）维持 core 橙恒定=「循环不变」系列主线。
- 局部类比**一物一喻继承附录 A**，不另造：小票（§3.2 配对）、复印店账单（§4.2 缓存）、搬家整理（§3.1 顺序）、没拆的快递（§3.3 unseen）、会议纪要 vs 便签（§4.3 scope）。每喻 1–3 句点亮直觉即切回机制画面，**失配拦截句随行**（口播或字幕补位）。零类比直讲合法。
- **旧版禁用词表**（差异化纪律，④ 校验时对 narration.md 逐词 grep 复核；按旧版骨架级框架词扩充）：师傅 / 台面 / 登记簿 / 扉页 / 目录员 / 夜班整理工 / 收台 / 掐中段 / 取货条 / 打烊 / 演进彩蛋 / 两本账 / 会丢的 / 不能丢的 / 记忆不是一个功能（含立碑意象）/ 工坊 / 裁中段 / 压条子 / 搬仓库 / 记录员 / 垫纸 / 包裹标签 / 回执 / 回单 / 撂活 / 时间铰链 / 吃得住缓存 / 前面算过的全白算 / 丢口味。约束：「两套机制」为 cardSub 通用语不禁，但**不得复用为收束框架**（旧 P6「记忆不是一个功能，是两套咬合的机制」的总结构型）——新收束框架唯一 = 五规律（§8.1）。

**记忆点节奏**（约每 60–90 秒一个，全部回溯事实源）：
