## 二、叙事策略

**主线一问一答闭环**：开场抛双问题——「窗口满了怎么腾地方」（会话内的经济学）与「腾掉的东西怎么找回来、换会话怎么还认得你」（跨会话的持久性）→ P1 全景给出五条设计规格的答卷框架 → P2–P5 逐机制回答「怎么修、凭什么说修好了」（每机制配钉点实测或原型破坏性实验）→ P6 收束回「两套机制咬合互不替代」的工程规律，并以「下期」点出并发问题引子（只点问题不预告机制）。

**开篇钩子候选矩阵（★ 待人工复核）**：

| # | 型 | 钩子文本（p0-01） | 吸引力留存逻辑 | 核心主干关联锚点 | 抛出的核心引子 |
|---|---|---|---|---|---|
| H1 | 细节具象型 ★ | 「这是一句被压缩吃掉的话：『用 tab 不用空格』，变成了『用户有代码风格偏好』。」 | 一句话的两种写法，具象到刺眼；「被吃掉」制造机制恶意感，3 秒锁注意力 | gl-notes §1 痛点 + §7.1 规律二（失真递增）；P5 召回走查用同一条记忆回收，首尾闭环 | 丢的话去哪了？怎么让丢不起的话找得回来？ |

★ 选定 H1（自动选定，待人工复核）。理由：零术语、具象到一句话的两种写法，「压缩必然丢细节」这一全片核心矛盾在 3 秒内成立；丢掉的「用 tab 不用空格」正是 P5 召回走查里被记忆库救回的那条（P0 抛、P5 收，首尾闭环不欠债）；H2 留存力亦强，作 p0-02 起的问题现场句并入（两全）；H3 数字好但缺「为什么」，作 P3 走查的记忆点兑现更值。

**视觉母题与局部类比纪律**：全片连续感由视觉母题统摄（恒定「管线级联 + 记忆库」双坐标 + 色彩语义 + 全景图换幕高亮），严禁把局部类比升格为贯穿剧场。口播类比只准入 gl-notes 附录 A 登记条目：本集拟用 #1 草稿纸（P0/P1 上下文首现）、#2 已付款未到货（P3 未读豁免）、#3 没拆的包裹（P3 fit，失配边界句随行）；#4 翻篇/续篇只在 P6 开放争议处一句带过或不进口播；每处 1–3 句点亮即切回，零类比直讲合法，不另造新喻。

**记忆点节奏**（约每 60–90 秒一个，全部取自 gl-notes §5 数字表与 §6 实验表，数字必带基线标尺）：
P0「tab → 偏好」丢细节具象（钩子即记忆点）→ P1 五条规格全景图 → P2「切错一刀，孤立结果 1 处，模拟 API 当场判 400」（§3.1 T5）→「批预算二十万字符、单条三万才落盘」（§3.2）→ P3「五十条线、头三条尾四十六条」（§3.3）→「六万三千字符压到一万六」（§3.4 T4）→「换序实验：完整落盘一变零、死占位十一处」（§6）→ P4「熔断三次」（§3.5/§5 CC）→「应急只保五条、重试一次」（§3.5）→ P5「四类型、选择至多五条、正文两万字符」（§4.1/§4.2）→「拆门控：两轮三变五，临时规则入库」（§6）→「拆回滚：两条变零条，索引对不上文件」（§6）→ P6 规律金句 + 边界护栏。

**理性收尾原则**：不贩卖焦虑。P6 落在 gl-notes §8 的护栏上——两章材料没有压缩质量与任务成功率的任何量化实验、教学参数是玩具值、CC 常量来自源码分析未钉版本会漂——把悬念留在真开放的争议二（记忆检索：LLM 判断还是向量索引，两者都没回答「什么该被记住」），再以「下期」引出并发问题（不预告机制细节）。

## 六、边界与不做的事

**系列递进边界（照抄口径卡，ep③ 不进入）**：多 Agent 共享记忆的并发一致性（材料只到文件锁为止——Dream 的 `.consolidate-lock` 仅作「整理是低频特权操作」的一笔，不展开一致性话题）、任务系统、后台任务与定时调度；压缩效果评估与 prompt cache 实证不进口播（材料未做）——召回两层的「开头稳得住才缓存得住」只作设计动机一句带过，不给任何命中数字或收益量化。

**开场装置衔接（场景层已有，剧本只做衔接）**：系列统一片头装置 leadInSec=23.5（705 帧 @30fps），口播 12 帧起播；片头三句口播固定在 narration SSOT 之外，剧本任何位置不复述、不改写；P0 冷启动直入本集钩子（不重复系列介绍、不自我介绍「我是谁」）；字数预算 3400–3600 不含开场。

**口播红线**：禁工坊系词汇及同族意象（工坊/车间/作坊/传送带/工序卡/副台/台面/收台/叫号器/排工板/插线口/师傅）；禁顺序词（上一集/上集/上期/下一集/下集/第 N 集/前一集/本系列），收尾预告只许「下期」，承接上集用无序号语义句（「活干完了」类自然表述）；观众可见层零信源站标识（不出现课程/站点名/章号，归属句用「拆过 Claude Code 源码的作者」句式，两轨差异口播只说「教学版的一次重铸」不点名轨道）；【三】级断言前 3 句内必带归属句；活数据不进口播；估算数带口径；Harness 不翻译（口播英文例外清单 = Claude Code + Harness）；「上下文」首现带白话句（草稿纸）；英文方法名（tool_use / tool_result / prompt_too_long / transcript / MEMORY.md 等）进角标不口播。

**双轨特色取用纪律**：main 轨演进（占位符幂等、seen/unseen、压前落盘三道保险 vs 站点两道）是「版本进化」叙事素材，只在 P3 集中兑现一处（占位符从「死」到「活」+ 未读豁免），P2 单条线常量化一笔带过，P4 当前请求分离一句点到——不逐节铺陈两轨 diff。
