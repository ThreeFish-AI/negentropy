## 二、叙事策略

**主线问题（P0 抛出、P6 回答）**
> 大厂能把「含义」治理好，你手边这个 AI 助手怎么办？——上下文层能不能像搭积木一样，自己搭一个？

**贯穿比喻体系：五块积木 + 一张生长图 + 一个通用插头**
- 蓝图 = **五块积木**（放什么 / 怎么找 / 怎么养 / 怎么信 / 怎么用）——正交，每块独立换新而不塌。
- 对象 = **公司的词条**：像维基百科的条目一样有「草稿→发布→争议→取代」的一生（状态机）。
- resolve = **唯一的前台窗口**：所有 AI 都从这一个窗口问，窗口按「相关/权威/热门/新鲜」递资料。
- MCP = **USB-C**：任何设备任何牌子，插上就是同一套治理。

**记忆点节奏（每 60–90 秒一个，共 11 个）**

| # | ≈时刻 | 记忆点 | 类型 |
|---|---|---|---|
| 1 | 0:30 | 你的 AI 助手每次都从零开始猜你们公司的词——它没有「入职第一天」 | 痛点共鸣 |
| 2 | 1:40 | 五块积木，每块都能单独换——这叫正交 | 架构之美 |
| 3 | 3:00 | 没有同义词的定义，在检索里是隐形的 | 反直觉 |
| 4 | 4:10 | 给 AI 的说明书要跟着定义走，不许写死在 prompt 里 | 工程纪律 |
| 5 | 5:00 | 一个词条的一生：草稿→发布→争议→裁决→被取代 | 状态机具象 |
| 6 | 6:10 | 挖出来的理解和人写的定义打架时，机器不许猜——自动选会让错的赢 | 冲突纪律 |
| 7 | 7:20 | 所有 AI 只许从一个窗口问——这个窗口叫 resolve | 契约之美 |
| 8 | 8:20 | 热度用对数封顶：一万次调用压不过一千次太多——防「刷热度」 | 工程细节 |
| 9 | 9:10 | 通用插头 MCP：插上它，任何 AI 都继承你全部的治理 | 平台时刻 |
| 10 | 10:30 | 门禁保证权限，不保证算术：477 对 48，治理不等于验证 | 理性收口 |
| 11 | 12:20 | 三百行零依赖的原型已经跑通了全部六机制——P0 已完成，路线图往后都是工程问题 | 可行性证据 |

**术语降落规则**（严格执行）
- 英文标识符**只进画面角标，不进口播**：`resolve` → 「前台窗口」（首现可说「问询」）；`catalog` → 「目录」；`provenance` → 「出身标签」；`log1p` → 「对数封顶」；`Ossie` → 「开放规范」（名字进角标）；`fail-soft` → 「坏了就退回原样」。
- **例外名单**（可口播）：**MCP**（本集主角之一，说「一个叫 MCP 的通用插头标准」）；**Horizon Context / Snowflake**（上集主角，提及须无顺序词）；产品名 Claude 等。
- 与上集共用类比系统（手册/前台/门禁卡）**不解释来历**——系列内观众自然衔接，新观众听比喻本身也自洽（比喻必须独立可懂）。

**证据分级的口播义务**
- 路线图 P1–P3 **未实现**，口播只能说「路线图上/接下来」——已验证的只有 P0（原型 selftest 全绿）。
- 【三】厂商数字（86.3% 等）本集只在价值论证处复引一次，仍带归属。
- 【四】477 vs 48 带第三方归属句。
- 【一】原型实测（T5/T6、C4、D4 等）压「本仓原型实测输出」角标。

**理性收尾**：不喊「人人都能造平台」。落点——**上下文层不是给 AI 的补品，是基础设施**，像数据库、像网络一样值得认真造一层；造多大便看你要养多少 AI。收尾句：「含义被治理好之前，AI 的聪明都是租来的。」

## 三、视觉语言

**色彩语义契约**（SSOT 在 [../video/src/design/theme.ts](../video/src/design/theme.ts)）

| 色 | 值 | 语义 | 对 `#0E1116` 对比度 |
|---|---|---|---|
| 工程蓝 `blueprint` | `#6FB1E8` | **蓝图与五层架构**——结构线、层边界 | 7.5:1 |
| 苔绿 `grown` | `#A3D977` | **生长**——生命周期、自纠环、草稿→发布 | 9.6:1 |
| 暖橙 `activate` | `#FF9F6B` | **激活与接线**——resolve、四因子、MCP 插头 | 8.0:1 |
| 警示红 `danger` | `#FF5C5C` | 冲突、越权、错误数字（语义唯一） | 5.6:1 |

**反枚举原则**：五层**不给五色**。色彩映射「**结构（蓝）/ 生长（绿）/ 接线（橙）**」三轴：画架构用蓝、画状态机与自纠用绿、画对外接口用橙。并列项统一 `panel` 底 + 编号。

**本集独有的视觉母题**

> **v2 新增（2026-09-13 改版）**：① **archify 回放窗**（`components/ArchifyClip`）——工程图 Play 录制（`pipeline/scripts/record_archify.py`，webm 为派生产物 gitignored、sidecar 入库）内嵌为全屏 88% 窗；② **代码走廊**（`components/CodeWalk` + `TerminalLog`）——lab/MCP 真实代码行帧级高亮 + selftest 原文逐行上滚；guided-learn 三拍的「实景」由它们承担。术语白名单更新：域名缩写 AI / SQL / MCP 可口播，代码标识符一律只进画面。
1. **五块积木**：P1 命名帧——五块积木从蓝图纸上立起、拼成一台机器，后续每幕抽一块放大讲。
2. **词条的一生**：状态机轨道——draft 起点站 → governed 站台 → conflict 岔道（人工裁决灯）→ superseded 缓行线 → rejected 终点站。
3. **唯一窗口**：所有 AI（圆形头像）排队到同一个窗口；窗口后面是四因子天平 + 两页手册。
4. **USB-C 插头**：MCP 插头插进「上下文层」机身，点亮的不是一台设备而是整排治理灯。
5. **三级对策台阶**：便宜的一级在脚下（表达式校验）、二级中段（对账告警）、贵的三级在顶（eval 兜底）。
