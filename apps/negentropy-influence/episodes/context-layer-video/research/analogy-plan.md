## 实体映射表（机制=意象物）

### v3 新税制映射（三面 / 五轴 / 六段两环 / G 法则 / 双管线）

- 【三面·验收面（防住什么坏法）】=放行判据案卷：机库把「什么算合格」事先写成册，每条坏法有堵法、有验收判据；蓝图 §1 的九簇 42 行登记簿=这本案卷的 Agent 版——登记簿可以跨结构修订长期存活（换分法不动案卷）
- 【三面·结构面（沿哪几条独立维度组织）】=机库职能分区：五个分区各管一摊互不牵连（对应五轴），换工具间的规整制度不动库房台账=「换 X 不动 Y」
- 【三面·时间面（对象一生怎么流动）】=一张工卡的六道手续加两个回环：入库登记→检验裁决→开工装配→复核锚定→纪要回灌→报废归档；复查发现错数回写手册（验证环）、漏油报告回写 MPD（进化环）
- 【五轴·资产轴（经营什么）】=受控库房：手册母本、航材、工具、技术档案，件件在册、带版次、受治理
- 【五轴·权威轴（谁说了算）】=放行席位：会签资格交集、RII 复核、执法点长在关盖那一步
- 【五轴·装配轴（这轮进窗什么）】=机位：机位时间与工卡夹，最小够用、能不带的都不带
- 【五轴·检索轴（候选从哪来怎么排）】=工具间：影子板统一索引，版次号+校准证书=信任归一
- 【五轴·复利轴（下一轮凭什么更好）】=培训室：漏油变工卡项、老师傅带徒、一次发现全机队受益
- 【六段·L1 采集纳管】=航材入库三道闸：鉴权、只收完整交付件、件号可解析——出身有出处，ghost 零容忍
- 【六段·L2 铸形裁决】=检验分类挂牌：结构校验（外键/成环/聚合）+语义裁决（挂哪科、谁说了算）
- 【六段·L3 装配执法】=开工装配：每卡重领当版页=每轮重装；落笔当场核资格=实时求值；卡面印章节号不印全文=指针不副本
- 【六段·L4 应答锚定】=RII 复核提问：出示带版次底稿、给不出写保留单、绝不静默瞎猜——三条出路
- 【六段·L5 沉淀回灌】=交接班纪要入库：写满按比例截断留痕，正式入档是最后一步（先草稿区攒着）
- 【六段·L6 衰减退役】=报废作废：作废页进废纸盒、报废单在案——死要有葬礼，降权不清退=目录腐化
- 【两环·验证环】=复查结论回写手册：错数复盘后改的是判据，不是只改这一次答案
- 【两环·进化环】=漏油报告回写 MPD：一次发现改常设间隔，全机队代代受益
- 【G1 执法点绑定】=闸门长在物理通道上：关盖必经 RII 席位，不靠自觉遵守
- 【G3 裁决权不自动化】=手册打架递工程裁决：系统绝不按引用量自挑
- 【G5 指针不副本】=库位牌与库位卡：大件只挂牌不搬进车间，用时凭牌取
- 【G6 死要有葬礼】=报废单与废纸盒：每件退场有记录
- 【G7 闭环可观测】=每个回环有回执：纪要签收、报告归档，看不到回执的回路按断链处理
- 【纳管管线·Ingest 登记指针】=收货登记台：件号/批次/供应商/适航证 CoC 一并登记，出处随行、不复制本体
- 【纳管管线·Normalize 归一】=开箱规整台：统一标签、四件套规整（章节路径/内容模块/多模态/摘要梯）；检验员手工规整、不动用老师傅判断=全程不调 LLM（口径差异须口播点破）
- 【纳管管线·Classify 分类】=分类挂牌位：存贮等级、所属系统五选一——挂牌决定后续怎么对待它
- 【纳管管线·Tier 分级】=上架分层：L0 高频小件进抽屉（≤256 字符）/L1 上货架（≤4000）/L2 大件只挂库位牌不搬进车间（指针不副本=G5）；数字带基线标尺呈现
- 【纳管管线·Tag/Index 打标与索引】=画格入账：影子板画轮廓格+台账登记（ctx:// 寻址）——第五道关产出**目录条目卡（库位卡）**落上目录货架
- 【读管线·① Resolve 主体解析】=门禁核验：谁领卡、持什么证、可见性边界——权限天花板实时求值
- 【读管线·② Plan 意图与预算】=领班派工排程：本卡干什么、机位时间预算怎么分
- 【读管线·③ Retrieve 双范式并行】=调当版页/按件号领料（精确查询）+按章节翻手册（召回范式）双路并行
- 【读管线·④ Fuse 融合重排】=台面摊开排序：多页参考哪页在手边——权威压过声量
- 【读管线·⑤ Guard 检查点】=复核关卡五项：可见性/作用域/效力/PII/Instruction 越权；不过的走橙色分流道进 dropped 留痕盒（只进不改）
- 【读管线·⑥ Compose 预算裁剪】=工卡夹装夹：token 预算裁剪、最小够用——倒 U 纪律
- 【读管线·⑦ Emit 组装交付】=交付开工：ContextBundle=配好料的工卡包，uri@version=卡号带版次
- 【桥段·目录条目卡（库位卡）】=钢蓝描边小卡带版次号与 ctx:// 角标：P2 第五关产卡落目录货架、P7 Retrieve 处同一张卡起飞落位——写读两图首尾相接的恒定视觉锚（M-001 同物同形）
- 【机制·复利三在线律】=「制度挂在墙上不等于有人在干」：触发器（到点交纪要）/消费者（有人读）/水位（写满标记）三件齐备跑在生产路径上，回路才算在线
- 【机制·宽进严出】=领料先抱一摞候选（top-150 宽进）→台面初筛（rerank 严出）→只带进机位的一小撮（top-k 截断）——截断是信噪比控制，不是省事
- 【机制·倒 U 红线】=机位上摊太多页反而找不着那页：填充过半性能常降、整视图 ~10 万 token 是 guideline 不是目标
- 【目标态口径】=双管线两段走图全程挂「蓝图·目标态」角标；P7 收尾一句明说「这是蓝图画的读路径——现状离它多远，下一幕去装配线上数」

### v2 世代条目（五源 / 五段 / 五层——服务 P1 投影表拍与既有机制叙事）

- 【五源·instruction 身份与规程】=工卡开工页：本卡机型、工序边界、执证资格、「按 AMM 某章执行」的指令段——身份与规程随卡下达、开卡即生效
- 【五源·memory 记忆·常驻画像 Core Block】=个人技术档案：执照等级、机型清单、历年复训与带教记录——跨班次常驻、不随工卡作废
- 【五源·knowledge 知识与知识图谱】=AMM/IPC/MPD 手册体系：几十万页章节互引的工程知识库（图谱=章节交叉引用）；有效母本只此一套、只存于文件控制系统
- 【五源·tools+skills 目录常驻+正文按需渐进披露】=工卡裁切+当版页：卡面只印本卡用到的章节号与工具格（目录常驻），正文开工时从系统调出当版页全文（正文按需）——可组合性仅弱对应工序编排，角标处理
- 【五源·session 会话历史与压缩】=交接班纪要：本班工卡签署轨迹=会话历史；已关闭工序折成一行、未关闭/保留/异常一字不折=压缩——触发器如实降格为制度（到点必交）而非容量（记满才压），角标口播差异
- 【五段·Collect 采集】=开工装配：调当版页、领工具对影子板、核资格——上下文是开工动作装配出来的，不是天然就有
- 【五段·Govern 治理】=签署链与会签资格：谁有资格签、谁必须 RII 复核、谁无权替代——治理先于动手
- 【五段·Activate 激活】=落笔那一刻：签字时授权必须仍有效（跨班/过期/转授作废）；机坪上用的必须是页脚带打印时刻的当版页——用时取母本
- 【五段·Verify 验证】=RII 检验员提问：命中出示带版次号底稿；做不了的写保留单、显式标注未核准跟着飞机走
- 【五段·Evolve 进化】=漏油→可靠性报告→MPD 间隔调整→常设工卡项→新人培训大纲：一次发现全机队受益、代代生效
- 【五层·对象层（放什么：口径单点）】=有效母本只在文件控制系统里一本：机坪上只有当版打印页，世上不存在第二本有效
- 【五层·目录层（怎么找：统一索引、信任归一）】=影子板轮廓格+卡面章节号=统一索引（每件工具、每个章节唯一定位）；信任归一=版次号与校准证书（只有带有效版次、可溯源校验的底稿可信）——语义检索半边留白，降格为结构化索引并角标
- 【五层·富化层（怎么养：显式/隐式双轨、冲突浮出）】=显性轨：手册/工卡/记录；隐性轨：老师傅手感与带徒口传（可提示、永不替签字）；冲突浮出：手册打架→技术请示单，两页并排钉上、各带版次出处、裁定回来前工序挂起
- 【五层·治理层（怎么信：权限天花板/出口执法/防投毒）】=单卡关盖资格=全部会签要求的交集（执照∩机型授权∩RII∩客户代表），每加一道会签能关盖的人只会更少（只减不增）、签字那刻当场有效；出口执法=关盖放行必经 RII；防投毒=工具必回影子板、页必出自系统，非受控来源不进卡
- 【五层·激活层（怎么用：预算分配/按需检索/验证锚定）】=机位时间+一块工卡夹：只切最小够用的页、只圈那几格工具（预算内最小高信号集）；按需=用时调母本；锚定=签字即锚定版次
- 【机制·口径只印一本且当场重算】=当版页制度：系统里唯一有效母本；每页开工当场调出、页脚带打印时刻、打印即用用毕即弃，背下来的力矩值一律当错——「重算」读作「用时取母本」，字面让步须口播点破（角标：这里的重算=每次回母本取数，不是重新计算一遍）
- 【机制·权限=交集天花板实时求值只减不增】=工卡会签栏：资格=交集，没有任何一纸文书能替别家抬门槛；跨班作废、过期作废、转授作废=落笔当场；粒度钉死「单张工卡的关盖资格」，绝不外推到个人总权限（个人一生可考证扩权）
- 【机制·验证题库（命中出示盖章底稿、未核准显式标注）】=RII 检验员提问→出示带版次号的手册页/校准证书；给不出=保留单显式标注、跟着飞机走
- 【机制·血缘台账（谁产出谁消费可溯）】=工卡自身携带的签署轨迹：每步谁签、依据哪一版页、卡此刻在谁手里——记录长在卡上，不另设账本/登记簿镜头（规避 E1 台账撞型）
- 【机制·新内容自动贴标纳管】=影子板画格：新工具进编制先画轮廓格，凡事有定位；不在板上的工具=不存在于系统
- 【机制·过期内容自信地错（staleness）】=过期版次手册页：不发黄不长毛、印得同样权威，按它干的每一步都一丝不苟，错的是页脚没人翻的修订号
- 【机制·两版答案打架并列浮出人工裁决】=技术请示单日：停工、两页手册并排钉在一起、各带版次出处递工程，裁定回来前挂起——如实按异常路径拍（常态一页定音，打架才并排上桌），不升格为常设面板
- 【机制·上下文是有限注意力预算（最小高信号集）】=机位时间+工卡夹容量：工卡天生按最小够用裁切，只带本卡要用的页、只占影子板那几格；装不下/超窗的活不硬塞，进保留单显式记账——载体换算（预算=工位资源而非信息容量），角标处理
- 【机制·错误修正回灌复利】=漏油→可靠性报告→MPD 间隔调整→常设工卡项→新人培训大纲：一次发现全机队受益、代代生效
- 【留白·系统维护的隐式信号】=剧场内无对应物，明说留白：Agent 侧系统自动养成的隐式信号（embedding/用法统计）在机库无原生画面——隐式轨只落人脑（师傅手感），只讲「隐性轨可提示、不可裁决」，不讲系统能自动养手感
- 【角标·session 压缩触发器差异】=制度触发（到点必交）vs Agent 容量触发（记满才压）：如实口播一句差异，不假装同构
- 【角标·tools 可组合性】=切页是静态裁切，「工具可组合调用」仅弱对应工序编排，降格表述
- 【角标·目录层语义检索】=剧场只有结构化索引（章节号定位），「按意思从大库找内容」无原生画面，半边留白

## 压测修补话术（七问闭包）



## 使用纪律（10 条）

1. 手册只能以「当版打印页」出场（页脚打印时刻、打印即用、用毕即弃），严禁出现整本大部头或规章墙镜头——这是与 E1「规章手册」家族的唯一邻域风险，靠渲染口径即可隔离
2. 签署轨迹一律长在工卡卡面上（谁签、依据哪版页），不另做登记簿/台账镜头；文件控制系统只作背景提一句、不展开取景——同时规避 E1「出入库台账」与 E3 书架两处撞型
3. 权限话术粒度钉死「单张工卡的关盖资格」，绝不外推到「某个人的总权限」：个人一生可以考证扩权，一旦讲人就破「只减不增」；口播模板=「他可以变强，但这张卡的门槛只会更多」
4. 「并列浮出」按异常路径拍：先立常态（一页定音、活照干），再拍停工钉两页——这是全片戏剧高点（整条产线为一处分歧停摆），千万不要升格成双屏常驻面板，否则就是档案自陈的「对异常流程的升格」
5. 「当场重算」必须口播点破「=每次回母本取数，不是重新算一遍」，否则观众会把机制记成查表——这是该剧场唯一需要主动承认的字面让步，藏着不讲会被较真观众抓
6. 隐式双轨的铁律台词：「手感可以提示、永远不能替手册签字」——禁拍成师徒并行裁决或系统能养手感；「系统维护的隐式信号」整层留白不讲
7. 注意力预算开口前先做载体换算（机位时间+工卡夹容量），不直接说「注意力」；预算=工位资源而非信息容量的差异用一句角标带过
8. ~24 分钟新鲜感靠工位轮转保底：航材收货区（入库五道关，与文件室合并取景）→机坪（开工/落笔）→文件室（当版页/技术请示）→放行席位（RII/关盖）→工具间（影子板）五站轮换，避免全片一张桌子；工卡作为英雄道具全程在画面里流转、逐渐盖满章——盖满=关盖=片尾构图；P7 七道工序横轨是工卡流转的总装时刻（每站一枚章）
9. 安全叙事取「为什么这么慢、这么较真」的程序美学，不渲染空难恐惧；利害感来自停场一分钟都在烧钱的静默压力，而非事故画面
