# 分镜：《AI 会自己开工吗？后台与定时》

> 逐字稿 SSOT：[narration.md](./narration.md)；视觉契约见 [planning.md](./planning.md) §三。
> 一镜 = 2–8 句共享主画面；句区间覆盖本幕每一句（`check_script.py` 强制）。
> 色名：`core` 陶土橙（循环——本集环一秒不停）· `later` 霜蓝（本集己色：不发生在这一轮的事）·
> `mech` 石青（机制）· `deny` 警示红。
> **镜号必须与 `scenes/*.tsx` 的 `<Sequence name>` 逐字一致**。
