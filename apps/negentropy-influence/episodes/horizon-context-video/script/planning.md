## 二、叙事策略

**主线问题（P0 抛出、P6 回答）**
> 你把整个数据库的钥匙都交给 AI 了，它为什么还是一本正经地答错？——缺的不是智能，是含义。

**贯穿比喻体系：一位每天失忆的天才实习生 + 大厦受治理带教中枢（规章与安防大厦）**
- **AI Agent** = **每天重新入职的失忆天才实习生**：数学与逻辑满分，但今天不记得昨天，完全不懂企业方言黑话与安全红线。
- **原始物理数据** = 机房里密码般的物理列名（如 `amt_ttl_pre_dsc`）。
- **七大承重机制单射绑定**：
  1. **M1 规章手册**（语义视图）：只印一本且本身就是计算器，当场按原始凭证套算给你看；结构校验门拦下非法地块（D6）。
  2. **M2 闸机逐页验放规则**（行列级访问策略）：机密页自动打码、越权行直接扣留，识别专用身份。
  3. **M3 闸机焊死承重墙**（语义级治理执行）：全部通道共用同一执法点，语义层成不了治理旁路（双层防线，D5 泄露对比）。
  4. **M4 核准题库与盖章底稿**（应答层验证锚定）：命中核准题直接出示底稿，未核准显式标注，绝不冒充背书。
  5. **M5 全楼出入库台账**（端到端列级血缘）：谁产出、谁消费、经谁转手，事后可查；入账必过解析门（D8）。
  6. **M6 实习生专用工牌**（Agent Identity）：权限是带教人的子集，权限天花板必须实时求值（D9），刷卡记录在案。
  7. **M7 机密自动贴标系统**（分类与标签驱动策略传播）：文件进楼自动识别密级，经一次性映射贴标联动闸机（D10）。
- **降级辅助体系**：速记秘书与见习助教（富化）、智能前台与评估尺（检索）、工作护照与安全插座（MCP/Ossie）。

**术语降落规则**（严格执行）
- 英文标识符**只进画面角标与代码走廊，不进口播**：`semantic view` → 「规章手册」（首现提一次「语义视图」）；`fan trap` → 「复印机陷阱」；`COUNT(DISTINCT)` → 「去重计数」；`NON ADDITIVE BY` → 「半可加规则」；`RBAC` → 「权限」；`VQR` → 「核准题库」；`lineage` → 「血缘台账」；`Restricted Session Scope` → 「权限天花板」。
- **例外名单**（可口播）：产品名 **Horizon Context**、**Snowflake**、**dbt**，标准简称 **AI / SQL / MCP / Agent**。
- 每个新机制首现必配比喻，且与主剧场世界观单射自洽。
- **裸 `Context` / `Agent` 一律用中文**（上下文 / 智能体），官方英文原句只进角标；**破坏性实验编号（D1–D10）只进角标与终端输出，不进口播**。
- **每个承重机制必须走满四拍**：类比 → 机制不变量 → 破坏性实验反证 → 一句话收口；缺任一拍不得进入下一机制（guided-learn 费曼三维考评的视频形态）。

**证据分级的口播义务**
- 【三】厂商自报基准数字（Snowflake 内测 25%、86.3%、建模数天到数分钟）**必须**前置声明「Snowflake 自己测的 / 官方口径」，画面压角标「厂商自报基准」。
- 【二】第三方独立复测（Anthropic 复测 21%）必须清晰区分，**绝不与厂商自报的 25% 混为一谈**。
- 【四】第三方批判（Typedef 477 vs 48）必须说「有家第三方机构复现指出……」。
- 【一】玩具复现与破坏实验（D1–D10）：首次出现明确「我们在自己的实验代码里复现验证」，画面压「本仓 lab 实测输出」。

**理性收尾**：
- 不鼓吹「AI 已经万无一失」，也不贬低为「纯属营销」。
- 落点：**AI 什么时候可信，不取决于它多聪明，取决于含义和规则有没有被治理**。在含义被治理好之前，AI 的聪明都是租来的。
- 引出下集钩子：把这套大厦的市政蓝图拆解成五块通用积木，自己动手搭一个。

## 三、视觉语言与色彩语义

## 五、边界与不做的事

1. 不做 Snowflake 商业产品促销与界面导购，纯粹拆解工程设计机制与系统原理。
2. 厂商基准数字必须声明归属，绝对严禁混淆为第三方独立评测事实。
3. 英文代码符号绝对不进口播，全部沉淀至代码走廊与画面角标。
4. 全片独立成篇，口播绝不出现其他系列片名、集数序号或顺序词（结尾仅用通用的「下期」）。
5. 实验数据与代码完全锚定本仓 `horizon_context_lab.py` 的确定性运行结果。
