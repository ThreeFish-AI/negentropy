**选题的独特价值**：市面讲「AI 幻觉」的内容都在讲模型。本集讲**含义不在数据里**这个非模型原因，且每个机制都有「我们亲手用玩具数据复现了一遍」的实测对照——把厂商叙事变成可检验的工程。

## 二、叙事策略

**主线问题（P0 抛出、P6 回答）**
> 你把整个数据库的钥匙都交给 AI 了，它为什么还是一本正经地答错？——缺的不是智能，是含义。

**贯穿比喻体系：一位每天失忆的天才实习生 + 一份永远最新的入职包**
- AI Agent = **每天都重新入职的实习生**：能力极强，但今天不记得昨天，没人给他讲过公司规矩。
- 入职包五件套逐一对应六机制：**公司手册**（语义视图定义）→ **手册里的算法纪律**（查询时重算）→ **门禁卡**（引擎级权限）→ **观察笔记**（从使用痕迹长出的理解）→ **前台问询处 + 签名 FAQ**（检索与验证问答）。
- 铁律：入职包不是发给实习生的文件，是**装在办公楼里的制度**——谁入职都自动生效。

**记忆点节奏（每 60–90 秒一个，共 11 个）**

| # | ≈时刻 | 记忆点 | 类型 |
|---|---|---|---|
| 1 | 0:30 | 两家独立实测：无上下文时 AI 答企业数据题只有两成多准确率 | 痛点数字 |
| 2 | 1:30 | 库里那列叫 `amt_ttl_pre_dsc`——含义不在数据里 | 具象共鸣 |
| 3 | 2:50 | 二十个看板、二十种「净收入」的算法，抄来抄去必然漂移 | 机制之美 |
| 4 | 4:10 | 一张一百块的订单，被复印三张后会计全加上了——三百块凭空出现 | 复印机陷阱 |
| 5 | 5:20 | 班级平均分的平均，不等于全校平均——16.0 分对真实 4.8 分 | 反直觉 |
| 6 | 6:10 | 银行卡余额能跨账户相加，不能跨天相加 | 反直觉 |
| 7 | 7:00 | SQL 完全合法，分析完全错误——valid SQL ≠ valid analytics | 金句 |
| 8 | 8:30 | 门禁装在电梯里：实习生、外包、AI，进门都得刷卡 | 治理具象 |
| 9 | 9:40 | 九千多张表，人工手册覆盖不到百分之五——手册写不完是常态 | 覆盖率现实 |
| 10 | 10:40 | 两个部门的「活跃用户」打架，机器不许猜，卡片摆上桌人来定 | 冲突纪律 |
| 11 | 12:40 | 门禁保证的是权限，不是算术——治理不等于验证（477 对 48） | 理性收口 |

**术语降落规则**（严格执行）
- 英文标识符**只进画面角标，不进口播**：`semantic view` → 「公司手册」（首现说一次「语义视图」）；`fan trap` → 「复印机陷阱」；`COUNT(DISTINCT)` → 「去重计数」；`NON ADDITIVE BY` → 「半可加声明」→ 口播说「能加不能加的规则」；`RBAC` → 「权限」；`Cortex Sense` → 「官方的挖掘工具」（名字进角标）；`verified query` → 「带签名的 FAQ」。
- **例外名单**（可口播）：产品名 **Horizon Context**（Snowflake 旗下）、**MCP**（下集主角，本集只说「一个通用插头标准」）、公司名 **Snowflake / dbt**。
- 每个新概念首现必配比喻，且比喻在画面里同时成立。

**证据分级的口播义务**（本集最容易出错）
- 【三】厂商自家基准数字（24.1%→86.3% / $1.76→$0.59 / <5% / 反超 10pct / 数月→一天）**必须**前 3 句内带「Snowflake 自己测的 / 官方口径」；画面压角标「厂商自家基准」。
- 【四】第三方分析（477 vs 48）必须说「有家第三方公司复现说……」。
- 【一】玩具复现数字（200/440 等）：P3 首次出现时建立框架「我们自己用玩具数据复现了一遍」，之后说「复现里」即可。
- 基线 21%（Anthropic 复测端）与 25%（Snowflake 内测）**不得混说成一个数**。

**理性收尾**：不喊「AI 全面可信了」，也不喊「都是营销」。落点——**AI 什么时候可信，不取决于它多聪明，取决于含义和规则有没有被治理**；治理还有它管不到的地方（治理≠验证）。收尾句引出「把这栋楼的设计图抽象出来」= 下期钩子（用「下期」不违规）。

## 三、视觉语言

**色彩语义契约**（SSOT 在 [../video/src/design/theme.ts](../video/src/design/theme.ts)）

| 色 | 值 | 语义 | 对 `#0E1116` 对比度 |
|---|---|---|---|
| 琥珀金 `manual` | `#E8C06A` | **受治理的手册**——定义、金标准、签名 FAQ | 8.9:1 |
| 青碧 `engine` | `#5CBFB0` | **引擎与计算纪律**——查询时重算、门禁执行 | 7.9:1 |
| 淡紫 `dig` | `#C9A0FF` | **长出来的理解**——隐式挖掘、冲突、自纠 | 7.0:1 |
| 警示红 `danger` | `#FF5C5C` | 错误数字、泄露（语义唯一不作装饰） | 5.6:1 |

**反枚举原则**：六机制**不给六色**。深层轴是「**手册（金）vs 引擎（青）vs 长出来的（紫）**」三股力量，六机制是三股力量的组合。并列项（五段式、四因子、三个病灶）统一 `panel` 底 + 编号，激活时才染色。

**本集独有的视觉母题**
1. **入职包**：P1 命名帧——一只公文包展开长出五件套（手册/算法页/门禁卡/观察笔记/前台铃），后续各幕逐件取用。
2. **复印机陷阱**：一张订单卡进复印机 → 三张副本 → 求和器爆红（$100→$300）。
3. **双层门禁**：大楼剖面——检索层是前台滤卡片（体验），执行层是电梯里的闸机（底线）；绕过前台直闯电梯 → 闸机照样拒。
4. **CONFLICT 卡片**：两张定义卡并列、中间一个大问号、**数字区刻意空白**。
5. **前台问询处**：一个问题气泡进来，四因子天平称重，抽出两页手册。
