# 拍摄执行方案（shooting-plan.md）——A 档 iPhone 主案

> 画幅 16:9 · 4K 主拍 · 纯手部 + 实物，不露脸。分镜见 `../script/storyboard.md`（镜号引用），红线见 `./redlines.md`。
> 场地：室内桌面棚（无窗房或夜拍拉帘，全程人工光保多日一致性）。素材落 `../out/raw/<日期>_<分组>/`。

## 1. 器材清单（A 档，可少量采购）

| 类别 | 清单 | 备注 |
|---|---|---|
| 主机 | iPhone（主拍）：4K30 为主，关键动作切 4K60（撕膜/磁吸/点亮留升格余量） | 锁 AE/AF、锁白平衡（对灰卡/白纸定标后长按锁定） |
| B 机 | 备用 iPhone：俯拍位 | 同锁参数；两机同帧率同白平衡 |
| C 机位替代 | 主机微距模式 / 微距附加镜 | ECU 插入镜（封条/表冠/表背） |
| 支撑 | 桌面三脚架 ×2 + 俯拍悬臂（灯架/稳固支撑物 + 夹具） | A 机 45°、B 机 90° |
| 灯 | 可调色温 LED ×2 + 柔光罩/漫射白布；小型背光灯 1（可选） | 主光大面积柔光；顶光柔屏给俯拍区 |
| 消反光 | CPL 偏振镜（手机夹式） | 拍表镜/屏幕时压反光 |
| 收音 | 领夹麦/近距电容麦（foley 同期参考）+ 第二手机近距收声 | ASMR 段独立近距离收录 |
| 道具辅助 | 中灰+深色双面桌板、无绒布 ×2、白棉手套、亚克力垫块、15° 手机支架、秒表/计时器、灰卡 | |
| 屏幕采集 | 新表实机录屏（迁移/功能演示）+ 每日定点电量截图 | watchOS 屏幕录制经配对 iPhone |

**B 档备胎（附录）**：全画幅微单 + 90/100mm 微距 + 35mm + 三脚架/悬臂 + 柔光箱×2 + 黑旗 + 滑轨 + 独立录音机——若个别英雄镜（撕膜、钛壳转盘）追求浅景深可补拍，主流程不依赖。

## 2. 布光与桌面

- 主光：45° 高位大面积柔光（模拟窗光），照亮桌面主体；反光板补阴影，明暗比约 2:1。
- 俯拍区：顶置柔光屏压平桌面反光；黑钛表体靠条形高光勾轮廓，原色钛靠均匀柔光罩质感。
- 反光控制：黑旗挡环境杂散光；表镜/屏幕加 CPL；拍屏幕时降室内灯防屏内反光穿帮。
- 白平衡全程锁同一基准（~5000K，对灰卡定标）；每日起播先拍灰卡帧 + 场记板帧（口播「Day N / 分组 / 镜号」），供剪辑对齐。
- 桌面：深灰哑光主台面 + 中性背景板；台面只留当镜道具（单一焦点律）。
- **频闪校准（Day0 首项）**：开机点亮后先试拍表盘 10s，检查滚动条纹；若有，调亮度档/快门（30fps 对 1/50 或 1/60 试验）直至干净——全程沿用该组合。

## 3. 机位语言

| 机位 | 角度 | 职责 |
|---|---|---|
| A 主机位 | 45° 侧俯 | 关系镜头：手 + 桌面 + 盒/表；上手 MS/CU |
| B 俯拍 | 90° 正俯 | 开箱全流程、内容物平铺、手机屏再现 |
| C 微距 | 贴近/滑轨 | 封条、表冠、表背、屏幕 ECU |
| D 手持 POV | 第一人称 | 外景佩戴、出门通话、日常日记 |

## 4. 多日拍摄日程

### Day 0 · 开箱日（一次性镜头链，整日核心）

**开拍前核对单**（全部打勾才开机）：
- [ ] 换货新盒（零售彩盒）未拆封确认；三机位（A/B/C）同录参数一致（同帧率/白平衡/分辨率）
- [ ] 旧零售盒排练 ×2：走位、焦点、撕封条手部路径（排练只用旧盒，禁碰新盒封条；两盒外观一致，开拍前在盒底贴可移除标签区分「旧/新」，标签不入镜）
- [ ] iPhone 电量 >80%、存储 >64GB×2；领夹麦试音；灰卡帧已拍
- [ ] 新表系统版本确认页面路径（首次开机流程截图备用）；联通 App 登录态确认（一号双终端入口找得到）
- [ ] 预打码客服截图已导入备用手机（原始记录不上桌）

**一次性镜头链（顺序即发生顺序，每镜 A/B 双机保底 + C 机微距插入）**：
1. 换货新盒静置/翻面（可摆拍，非一次性）→
2. **撕封条（一次性）**：B 俯拍 ECU 慢动作留 4K60；foley 独立近距收录 →
3. **开盒 + 内容物首见（一次性）**：B 俯拍全景 + A 45° 备份；逐件清点平铺（对白光拍清点镜）→
4. **首次开机点亮（一次性）**：C 微距屏幕；点亮瞬间 4K60 →
5. **配对动画（一次性）**：手机与新表同框（A 45°），按真实流程走 →
6. **备份恢复（一次性，备份来自配对 iPhone）**：进度条屏幕实录（iPhone 端录屏）+ 手表特写间歇拍 →
7. **eSIM 开通（一次性）**：联通 App 退订 → 手表重新开通全程屏幕实录；「信号图标绿了」特写多拍几秒留互动停顿
- 迁移全程计时器入画（实数回填 p3-04）。

**Day0 其余（非一次性，可补拍）**：新旧双盒并排对照镜（旧盒三件套铺开）、新盒开封后空盒细节、checkcoverage 保修查询（屏幕录制）、零售盒内充电线特写（5W 慢充伏笔）。

### Day 1–4 · 使用日记（每日 10–15 分钟固定项 + 随机项）

固定项（同时区完成，供电量序列与日记剪辑）：
- [ ] 晨/晚电量截图（控制中心电量 + 时间可见）——续航推算唯一数据源
- [ ] 15–30s 佩戴生活随手拍（D POV）：通勤/工位/运动任一
- [ ] 蜂窝状态检查记录：控制中心蜂窝图标 + 设置-蜂窝状态页（复发观察证据链，红⑥/⑦口径）

随机项（按分镜需要触发）：窗边/户外无手机独立通话（p4-02/03）、智能叠放单手演示（p5-08，重复多 take）、健康 App 心率/HRV 页实拍（p4-11/12）、夜间充电实拍（p5-05/06，拍 0%→挂上充电器瞬间即可，不真拍两小时）。

### Day N · 收尾（观察期结束）

- [ ] 收尾三镜：新旧空盒 + 表同框 WS、上手佩戴定格、桌面收场
- [ ] 复发观察结论落账（A/B 版选择依据）；⟨TBD⟩ 全清单回填 narration → 重跑④校验

## 5. 按布光分组的拍摄顺序（Day0 内）

1. **顶光组（俯拍区）**：新盒外观轮转 → 撕封条（一次性）→ 开盒清点（一次性）→ 内容物与旧盒三件套并排平铺 → 双盒对照
2. **主光组（45° 区）**：配对/恢复流程手部（一次性）→ 上表带 → 充电上桌 → 手部 B-roll
3. **微距组**：钛壳/表冠/扬声器/表背 → 屏幕演示（智能叠放/健康页/控制中心）→ 充电线细节
4. **屏幕再现组**：预打码客服截图屏拍（匀速滚动，禁快放）
5. **外景/窗边组**：独立通话、佩戴 POV
6. **补拍组**：转场空镜、封面静帧（高角度）、收尾镜

## 6. 演示设置核对单（功能演示前逐项）

勿扰模式开（防通知弹窗穿帮）/ 亮度锁 100% / 真彩显示关 / 剧场模式关 / 专用演示表盘统一 / 抬腕亮屏开。演示与口播功能一一对应（Visual Lock 禁项）。
