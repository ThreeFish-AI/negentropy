# 剪辑方案（editing-plan.md）

> 剪辑基线：`../script/narration.md`（句 id SSOT）+ `../script/storyboard.md`（镜号）。红线见 `./redlines.md`。
> 时间线：1080p30 或 4K30 时间线（素材 4K 裁切余量）；升格素材 60fps conform。

## 1. 节奏目标

- **宏观**：全片 4:50–5:10；平均镜长 2.5–3.5s；全片约 95–110 刀；相邻镜长短交替（连续同长 ≤2）。
- **分段**：P0–P1 快切 1.5–2.5s（故事段堆密度）；P2 ASMR 区 6–25s 长镜（全片唯一慢区，前后形成速度反差）；P3–P5 主流 2–3.5s；P6 收口渐稳（3–5s）。
- **微观**：每 3–5s 一次可见变化（切镜/运镜/图形入场任一）；重音镜（1–2s 数字 punch / verdict 卡）每 20–40s；记忆点每 60–90s 与 narration 幕对应。
- **Land on the Word**：以 VO 波形为钟——关键词音前 4–6 帧起图形入场/切点，词音落定即到位；口播「六千五」「十二毫米」「五瓦」等数字词与参数卡严格对位。
- **互动停顿（B站）**：撕封条（~1:40）、保修查询序列号（~3:15）、信号复活（~2:30）各留 0.5–1s 不切镜、不加图形，交给弹幕。
- **开场 0–8s**：≥3 次画面变化（新盒静置→撕封条起手→切 45° 新旧双盒），首句 VO 在第 1–1.5s 进入。

## 2. 声音三层

| 层 | 规格 |
|---|---|
| VO | 后期人声（vo-direction 情绪分块导引）；响度锚 **-14 LUFS**、峰值 ≤-6dB；判断句前留 0.3s 微停顿；降噪保守（保人声质感） |
| foley | 同期参考声 + 独立补录（撕封条/纸壳/磁吸表带/表冠/触屏点击）；ASMR 窗 foley 独占全频（音乐静默、VO 缺席）；非 ASMR 段 -18~-24dB 垫底；**禁用音效库替换开箱真实声** |
| 音乐 | 低存在感电子/极简底；VO 段 duck -12~-18dB（侧链）；ASMR 窗全静默；P1 故障档案段可换暗色低频底（避开记忆点词音）；幕转折处一次起伏换气 |

- 音频交付：-14 LUFS integrated、true peak ≤ -1dB。
- BGM 授权：可商用曲库（跨平台分发核对授权范围，红线⑪）。

## 3. 字幕与图形规范

- **字幕**：中文底部居中、恒单行、一句一条（= 句 id）与 VO 同步；白字 `#F5F2EC` + 黑边/半透明底条；单条 ≤35 字，超长按语义拆连续字幕窗（禁 CSS 式自动换行与压字距）；置于底部 5–15% 区，守 80% 安全区。
- **角标系统**：术语英文角标（右上：watchOS 27.0.1 / HRV / Smart Stack / eSIM·一号双终端）；数据口径角标（数字旁小字：「官方口径」「个人体验·非严谨测试」「国行 2026-09 发布价」）。
- **参数卡**：全片硬参数 100% 图形承载（口播零列报）；每卡停留 ≥1.5s，落定后 ≥10 帧再切；卡上只放数字/标签/口径，**禁逐字复述口播句**（逐卡人工查）。
- **色彩语义**：橙 `#FF9F0A` = 此前记录/待定；绿 `#34C759` = 当前验证/通过；仅用于新旧对照，不做装饰。
- **章节条**：顶部 10% 细进度条 + 幕名标签（「不是开箱/故障档案/第二只盒子/数据搬家/复查与体检/续航日常/换货答卷」）。
- **打码层**：剪辑工程内参数化跟踪（不透明块+模糊双保险，红线⑧）；导出前全片逐帧复查打码漂移。

## 4. 调色

- 中性自然基底，钛金属高光质感（不过暖不过饱和）；灰卡帧统一多日白平衡/曝光基线。
- 分区微调：P1 故障档案段降饱和 10–15% + 阴影偏冷青（证据/回忆感）；P2 开箱恢复暖中性（仪式感）；ASMR 段可整体降 5% 饱和做呼吸区隔。
- 屏幕素材（录屏/屏拍）单独匹配亮度色温后入画；画中画加 1px 中性描边。

## 5. 交付规格

| 平台 | 规格 |
|---|---|
| 母版 | 4K UHD 3840×2160 / 30fps / H.264 高码率（45–60Mbps）+ 1080p 版 |
| B站 | 1080p 或 4K 上传；**烧录硬字幕**；8 章节时间戳（幕名即章节名）；简介区声明块（价格口径/国行功能口径/换货时间线/打码说明）；置顶评论放事实底账摘要 |
| YouTube | 同母版 + 英文字幕轨（可选）；描述区置顶事实来源与打码说明 |
| 封面 | 1920×1080（B站另出竖版辅助图）；封面受红线②⑪约束 |
