> 与 [narration.md](./narration.md) 的句 id 对齐；每个「镜」（beat）覆盖一段连续句 id，是 Remotion 场景组件的实现规格。
> 时长以逐句音频 manifest 实测为准，此处仅给目标占比。
> 视觉体系（本集独立契约）：深色底 `#0E1116`；终端绿 `#4ADE80`=可执行证据（全片主色，确认绿与之合一）；洋红 `#FF6EC7`=进化动作；警示红 `#FF5C5C`（仅失败态，恒配 ✗）；金句卡衬线体；五对象不配五色（反枚举原则）。

## 实现映射

每幕一个 Remotion 场景组件（`video/src/scenes/`）：P0Hook / P1Boundary / P2FiveObjects / P3WhenEvidence / P4Eval / P5Trust / P6Ending。
「镜」作为组件内 beat：按句 id 区间用 `beatWindow(sentences, sceneFrom, from, to)` 取窗口，Sequence `name`=镜号。
公共组件复用 `cards.tsx`（QuoteCard/FadeUp/Pill）+ `Subtitle` + `NarrationAudio`。

渲染缺陷自检（承接上集 review 教训）：①百分比定位统一 px 居中；②底部角标 `bottom ≥ 150` 避开字幕条；③`pathLength` 与像素级 dasharray 不混用；④片尾渐黑窗口从末句实时长推导，不写死帧数。
